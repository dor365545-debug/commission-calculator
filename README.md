# הצהרת בריאות דיגיטלית – מדריך יד ביד (מותאם iPhone / iPad)

הטופס הזה בנוי במיוחד כך שאפשר לעבוד איתו גם רק מהנייד או מהטאבלט:
1. שאלות אמריקאיות (כן/לא).
2. פתיחת ענפים אוטומטית אחרי תשובה חיובית.
3. שדות מלל חופשי לפירוט.
4. שליחה אוטומטית ל-Webhook בסיום.

---

## שימוש מלא רק מ-iPhone או iPad (כולל iPadOS 26.3)

### שלב 1: שמירת הקובץ
- שמור את `index.html` באפליקציית **קבצים** (Files), למשל בתיקיית iCloud Drive.

### שלב 2: פתיחה מהאייפד/אייפון
- פתח את אפליקציית **קבצים**.
- לחץ על `index.html`.
- אם הוא לא נפתח יפה ב-Safari, לחץ על **Share** ואז **Open in Safari**.

### שלב 3: בדיקה מהירה
- סמן "כן" באחת השאלות וראה שנפתח ענף המשך.
- כתוב פירוט חופשי.
- לחץ "שליחת ההצהרה" ותראה סיכום בתחתית.

### שלב 4: איך לגרום לנתונים להגיע אליך אוטומטית
- פתח חשבון חינמי באחד מהשירותים: **Formspree** או **Make** או **Zapier**.
- צור Webhook/Endpoint לקבלת נתונים.
- העתק את הכתובת.
- חזור לטופס והדבק בשדה **"כתובת Webhook"**.

> טיפ באייפון/אייפד: לחיצה ארוכה בתוך השדה תאפשר Paste מהיר.

### שלב 5: שליחת קישור ללקוח
כדי לשלוח ללקוח קישור (ולא קובץ), צריך להעלות את `index.html` לשירות אירוח:
- Netlify Drop (קל מאוד למתחילים)
- Vercel
- GitHub Pages

אחרי העלאה תקבל URL ציבורי. אותו שולחים ללקוח בוואטסאפ/מייל.

---

## התאמות שכבר בוצעו לנייד
- כפתורי בחירה גדולים יותר ללחיצה נוחה באצבע.
- אזור כפתורי פעולה נוח יותר במסך קטן.
- תמיכה טובה יותר בתצוגת Safari בנייד.

---

## התאמה אישית מהירה
- מחליפים נוסח שאלות ישירות ב-`index.html`.
- מעדכנים שמות נוסעים לדוגמה לשמות האמיתיים שלך.
- אפשר להוסיף עוד שאלות במבנה של `div.question`.

---

## הערה חשובה
זהו כרגע פרויקט Frontend:
- בלי Webhook: תוצג רק תוצאת סיכום על המסך.
- עם Webhook תקין: הנתונים יישלחו אוטומטית ליעד שהגדרת.
