# מחשבון מחיר ביטוח נסיעות (שלב 1)

דף סטטי אחד בעברית (RTL) שמחשב מחיר לפי:
- תאריכי יציאה/חזרה
- מספר מבוטחים
- גיל יחיד או רשימת גילאים
- אזור יעד
- תוספות

החישוב והטבלאות מוגדרים כרגע כ-**placeholder** בתוך `index.html`:
- `PRICING_TABLE` – מחיר בסיס ליום לפי גיל ואזור
- `ADDONS` – תוספות (סכום קבוע ליום או אחוז)

אפשר להחליף ערכים אלה בקלות בהמשך.

## הרצה מקומית מהירה
1. פתחו טרמינל בתיקיית הפרויקט.
2. הריצו:
   ```bash
   python3 -m http.server 8080
   ```
3. פתחו בדפדפן: `http://localhost:8080`

## פריסה (Deploy) פשוטה ללא קוד
### אפשרות A: Netlify Drop
1. היכנסו ל-https://app.netlify.com/drop
2. גררו לשם את הקובץ `index.html` (או את כל התיקייה)
3. תוך כמה שניות תקבלו לינק ציבורי.

### אפשרות B: GitHub Pages
1. העלו את הקבצים לריפו ב-GitHub.
2. היכנסו ל-`Settings` → `Pages`.
3. תחת `Build and deployment` בחרו `Deploy from a branch`.
4. בחרו branch ראשי (`main`) ותיקיית root (`/`).
5. שמרו – יתקבל URL ציבורי.
